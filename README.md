A modern, interactive, and highly responsive personal portfolio website designed to showcase my journey, skills, and projects as a **Software Quality Assurance (SQA) Engineer**. The UI is built with a custom Dark Theme, interactive Glassmorphism cards, and neon cyan accents to represent the precision and tech-centric vibe of Quality Assurance.

## Key Features

- **Modern UI/UX:** Built with a dark theme and custom "SQA Vibes" (Neon Cyan highlights).
- **Glassmorphism Design:** Beautiful translucent cards and background blur effects.
- **Smooth Animations:** Scroll effects, dynamic rendering, and hover states powered by Framer Motion.
- **Fully Responsive:** Accurately optimized for all screen sizes (Large Monitors, Laptops, MacBooks, Tablets, and Mobile devices).
- **Interactive Navigation:** Sticky, transparent-to-solid animated navbar with glowing active states.
- **Dynamic Contact Form:** A beautifully designed "Let's Talk" section for seamless communication.

---

## 🛠️ Tech Stack & Tools

- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (with custom utility classes)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 📂 Project Structure

An industrial-standard component-based architecture is maintained:

rajin-portfolio/
├── public/

├── src/
│   ├── components/
│   │   ├── Navbar.jsx       # Interactive Navigation

├── package.json
